Target-decoy false discovery rate

Description

An R6 class that estimates the false discovery rate (FDR) of target-decoy search results. When the object is created, the hits are sorted from best to worst score and two FDR estimates are computed at each score:

  • fdr_concatenated: the FDR of a concatenated target-decoy search, estimated as 2 * decoys / all hits (Elias and Gygi 2007).

  • fdr_simple: the FDR estimated as decoys / targets (Käll et al. 2008).

Both estimates are fractions in [0, 1]: values above 1, e.g. where the best hits are decoys, are set to 1.

The q-value of a hit is the lowest FDR at which it is accepted: the smallest estimate at its own or any worse score. Within tied scores, decoys are ranked before targets, so the result does not depend on the input order and tied targets get the conservative FDR.

The decoys are given as logical flags. For protein IDs whose decoys start with REV_, pass decoy_hit = grepl(“^REV_”, id), and id = id to keep the IDs in table.

The object cannot be changed: its fields are read-only and its methods only read them. clone() copies an object. See vignette(“TargetDecoyFDR_Example”, package = “prozor”).

Value

TargetDecoyFDR$new() returns a TargetDecoyFDR R6 object; see Methods.

Active bindings

larger_better
TRUE if a larger score is better (read-only).
n
Number of hits (read-only).
table

The hits from best to worst score, as a data frame (read-only) with the columns:

  • order: the position of the hit in the input.

  • id: the ID of the hit; only when id was given.

  • score, decoy_hit: the sorted input.

  • fdr_concatenated, fdr_simple: the FDR estimates at the score, as fractions in [0, 1].

  • q_value_fdr_concatenated, q_value_fdr_simple: the q-values of both estimates, as fractions in [0, 1].

TargetDecoyFDR$new()

Sort the hits from best to worst score and compute both FDR estimates and their q-values.

Usage 
TargetDecoyFDR\$new(score, decoy_hit, larger_better = TRUE, id = NULL)
Arguments
score
Search engine scores, without NA.
decoy_hit
Logical, TRUE for decoy hits, one per score, without NA.
larger_better
TRUE if a larger score is better, FALSE if a smaller score is better.
id
IDs of the hits, e.g. protein IDs, one per score; NULL (default) for none.
Returns

A new TargetDecoyFDR object.

TargetDecoyFDR$print()

Print the numbers of hits and decoys, larger_better, and the scores at fdr_simple q-values of 0.01 and 0.05 (none if no score reaches them).

Usage 
TargetDecoyFDR\$print(...)
Arguments
…
Not used.
Returns

The object, invisibly.

TargetDecoyFDR$score_at()

Find the score cut-off for a given FDR.

Usage 
TargetDecoyFDR\$score_at(
  q_value = 0.01,
  method = c("fdr_simple", "fdr_concatenated")
)
Arguments
q_value
The FDR as a fraction, like the q-values in table: 0.01 for 1 %.
method
The FDR estimate to use: “fdr_simple” (default) or “fdr_concatenated”.
Returns

The least strict score whose q-value is at most q_value. An error if no score reaches it.

TargetDecoyFDR$plot()

Plot the score distributions and q-values: two panels on a shared score axis, the histogram of target and decoy scores, and the q-values of both FDR estimates in percent. When smaller scores are better and all scores are positive, the score axis is logarithmic.

Usage 
TargetDecoyFDR\$plot(bins = 100)
Arguments
bins
Number of histogram bins.
Returns

A ggplot object.

Examples

library("prozor")

data(fdr_sample)
# smaller scores are better; decoy IDs start with REV_
fdr <- TargetDecoyFDR$new(
  fdr_sample$score,
  decoy_hit = grepl("^REV_", fdr_sample$protein_id),
  larger_better = FALSE,
  id = fdr_sample$protein_id
)
