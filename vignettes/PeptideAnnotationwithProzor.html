Peptide Annotation and Protein Inference

Author

Witold Wolski

Published

March 16, 2017

Introduction

This Vignette describes how the greedy_parsimony() function can be used to infer proteins from peptide identifications using the Occam’s razor principle. The method tries to find a minimal set of proteins which can explain all the peptides identified.

Protein Inference

We can now identify a minimal set of proteins explaining all the peptides observed for both databases

precursors <- distinct(specMeta, peptideModSeq, precursorCharge, peptideSeq)

# peptide protein matches as points; rows and columns sorted by their number of matches
plot_matches <- function(pepprot) {
  peptide_rank <- rank(-Matrix::rowSums(pepprot > 0), ties.method = "first")
  protein_rank <- rank(-Matrix::colSums(pepprot > 0), ties.method = "first")
  nonzero <- Matrix::summary(pepprot)
  ggplot(data.frame(peptide = peptide_rank[nonzero$i], protein = protein_rank[nonzero$j])) +
    geom_point(aes(x = protein, y = peptide), shape = 15, size = 0.5) +
    scale_y_reverse() +
    labs(x = "proteins, most peptides first", y = "peptides, most proteins first")
}

Conclusion

We see that the number of proteins needed to explain all the peptides is practically identical for both databases. Also in practice using a database with more entries does not lead to more identified proteins. On the contrary, it might even reduce the number of proteins identified.

inference <- data.frame(
  database = rep(c("All", "Canonical"), each = 2),
  stage = factor(rep(c("before", "after"), 2), levels = c("before", "after")),
  proteins = c(
    length(unique(annotAll$protein_id)), length(unique(unlist(xxAll))),
    length(unique(annotCan$protein_id)), length(unique(unlist(xxCAN)))
  )
)
ggplot(inference, aes(x = stage, y = proteins)) +
  geom_col(fill = "#0072B2") +
  geom_text(aes(label = proteins), vjust = -0.3) +
  facet_wrap(~database) +
  labs(x = "protein inference", y = "proteins")
